# stock-research

미국 주식 티커(예: `NVDA`)를 입력하면 **SEC EDGAR 공식 API**에서 아래 정보를 가져와
**한국어 요약 리포트**(`reports/티커_날짜.md`)를 만들어 주는 프로그램입니다.

- 최근 **8-K** 공시 5건 (회사에 중요한 일이 생겼을 때 내는 수시 공시)
- 최근 **90일 Form 4** 내부자 거래 (임원·이사·대주주의 자사 주식 매매 신고)

---

## 1. 준비물: 파이썬 설치 (처음 한 번만)

이 프로그램은 **파이썬 3.8 이상**만 있으면 됩니다. 따로 설치할 패키지는 없습니다.

1. 터미널(맥) 또는 명령 프롬프트(윈도우)를 엽니다.
   - 맥: `Spotlight(⌘ + Space)` → "터미널" 검색
   - 윈도우: `시작` → "cmd" 검색 → 명령 프롬프트
2. 아래를 입력하고 엔터를 눌러 파이썬이 있는지 확인합니다.
   ```
   python3 --version
   ```
   (윈도우에서는 `python --version`)
3. `Python 3.x.x` 같은 글자가 나오면 준비 완료입니다.
   오류가 나오면 <https://www.python.org/downloads/> 에서 설치하세요.
   (윈도우 설치 시 **"Add Python to PATH"** 체크박스를 꼭 켜세요.)

## 2. 코드 내려받기 (처음 한 번만)

GitHub 페이지의 초록색 **Code** 버튼 → **Download ZIP** 으로 받아서 압축을 풀거나,
git을 쓸 줄 안다면:

```
git clone https://github.com/azkabantuna/stock-research.git
```

## 3. 실행하기

터미널에서 내려받은 폴더로 이동한 뒤 실행합니다.

```
cd stock-research
python3 research.py NVDA
```

- 윈도우는 `python3` 대신 `python` 을 입력하세요.
- `NVDA` 자리에 원하는 티커를 넣으면 됩니다. (예: `AAPL`, `TSLA`, `MSFT`)
- 티커 없이 `python3 research.py` 만 입력하면 티커를 물어봅니다.

실행하면 이런 화면이 나옵니다.

```
[1/4] NVDA 회사 정보를 찾는 중...
      → NVIDIA CORP (CIK 1045810)
[2/4] 최근 공시 목록을 가져오는 중...
[3/4] 최근 90일 내부자 거래(Form 4)를 읽는 중...
[4/4] 리포트를 작성하는 중...

완료! 리포트 파일: .../reports/NVDA_2026-10-09.md
```

Form 4가 많은 회사는 1분 정도 걸릴 수 있습니다. (SEC 규칙상 1초에 10번 이하로만 요청하기 때문)

## 4. 리포트 보기

`reports` 폴더에 `티커_날짜.md` 파일이 생깁니다.
`.md`(마크다운) 파일은 메모장으로도 열리지만, 표가 예쁘게 보이려면
**VS Code**, **Typora**, 또는 GitHub에 올려서 보는 것을 추천합니다.

리포트에 들어 있는 내용:

| 섹션 | 내용 |
|---|---|
| 한눈에 보기 | 최근 8-K 요지, 내부자 장내 매수/매도 건수·금액 합계 |
| 최근 8-K 5건 | 제출일, 항목 번호와 한국어 설명(예: 2.02 실적 발표), 원문 링크 |
| 내부자 거래 | 사람별 매수/매도 금액 요약, 거래별 상세(종류·주식 수·단가·10b5-1 여부·원문 링크) |

## 5. SEC 규칙 (User-Agent 이메일)

SEC는 자동으로 데이터를 받아가는 프로그램에게 **연락 가능한 이메일을 User-Agent에 넣으라고** 요구합니다.
이 프로그램은 `research.py` 맨 위의 `CONTACT_EMAIL` 값을 사용합니다.

이메일을 바꾸고 싶다면 두 가지 방법이 있습니다.

- `research.py`를 열어 `CONTACT_EMAIL = ...` 줄의 이메일을 고치기
- 또는 실행할 때 환경변수로 지정하기
  ```
  SEC_EMAIL=you@example.com python3 research.py NVDA
  ```

## 6. 문제가 생겼을 때

| 메시지 | 해결 방법 |
|---|---|
| `티커 'XXX'를 SEC 목록에서 찾지 못했습니다` | 티커 철자를 확인하세요. 미국 상장 종목만 됩니다. |
| `SEC가 요청을 거부했습니다(403)` | 이메일 설정을 확인하고, 몇 분 뒤 다시 실행하세요. 회사·클라우드 네트워크에서는 막힐 수 있으니 집 인터넷에서 시도해 보세요. |
| `인터넷 연결에 문제가 있습니다` | 인터넷 연결을 확인하세요. |
| `python3: command not found` | 1번 파이썬 설치를 다시 확인하세요. (윈도우는 `python`) |
